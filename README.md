# Crayon Inventory Tracker (塗鴉風盤點追蹤系統)

這是一個以現代網頁技術構建、專為倉儲與現場設備清點設計的**盤點追蹤管理系統**。系統以活潑的「手繪塗鴉風」 (Crayon/Doodle UI) 作為視覺主軸，將枯燥的盤點與績效管理轉化為生動、直覺且充滿互動的全新使用體驗。

經過多次更新，本系統已經具備強大且完善的盤點管理與績效追蹤機制。

---

## 🚀 核心技術架構
- **前端框架**：React + TypeScript + Vite
- **UI 呈現**：客製化 Vanilla CSS 手繪塗鴉風格 (包含 Caveat 手寫字體、手繪不規則外框、豐富鮮明的色彩)
- **圖表套件**：Recharts
- **後端與資料庫**：Firebase (Firestore) 即時資料庫

## 📋 詳細功能說明與範例

### 1. 📊 儀表板 (Dashboard)
儀表板是系統的指揮中心，讓管理者能以最快速度掌握盤點任務進度與人員績效。
- **西元年份與任務篩選**：可選擇特定年份或「全部年份」，並支援下拉選單選擇特定「盤點任務」。
  - *範例：當選擇「2026年度大盤點」任務時，儀表板的所有數據、圖表、以及人員清單都會自動過濾，只顯示該任務的相關資料。*
- **專屬任務進度列**：當選定任務後，畫面上方會顯示該任務的總進度，包含已指派的盤點單數量、剩餘可指派數量與任務所需總數量。
  - *範例：任務設定目標 100 筆，目前已指派 60 筆，進度列會填滿 60%，並標示「剩餘 40 筆未指派」。*
- **人員盤點績效卡片與清單**：
  - 獨立列出所有職責為「盤點」的人員卡片，顯示每人負責的總單數、本月指派數及完成數。
  - 卡片下方直接列出該人員「盤點中」的單號清單（支援每頁 5 筆的分頁功能）。
  - *範例：點開人員「王大明」的卡片，除了看到他已完成 10 單之外，下方的清單還會顯示他目前手邊正在進行的 3 張盤點單（例如 260701），單號旁會帶有彩色標籤標示所屬的任務名稱，並在右上角以紅色手繪徽章標示待辦數量。*

### 2. 📅 行事曆管理 (Calendar Management)
結合了任務排程、國定假日與補班日設定的智慧行事曆，是精確計算「盤點花費工作天」的核心。
- **月曆視覺化顯示**：以月曆形式呈現，每天的格子內會顯示當天進行中的所有「盤點任務」。
  - *範例：若「Q3 夾位清查」任務期限為 7/1 ~ 7/5，則月曆上的 7/1 到 7/5 都會出現該任務的彩色區塊。每個任務系統會自動分配不同的鮮明顏色以便區分。*
- **任務完成狀態即時標示**：
  - 若任務的所有盤點項目都已完成（以最後一項完成的那天為準），該天的任務區塊會以明顯文字與勾勾標示「✔️ 已完成」。
  - 若任務到期且仍有未完成的項目，在最後一天的區塊右上角會出現紅色的「❌ 未完成」標籤。
  - *範例：任務期限到 7/31，若 7/27 就完成所有項目，則 7/27 的月曆格子上會出現「✔️ 已完成」標記。*
- **放假及補假清單管理**：在月曆下方提供完整的假日設定清單，支援分頁與年月搜尋。
  - 系統內建台灣國定假日，可自訂「放假」或「補假」。
  - 歷史假日會以灰色底色淡化顯示，方便與未來的假日區分。
  - 這些設定會被系統用於精準扣除週末與假日，只計算實際的「工作天數」。

### 3. 📝 盤點任務管理 (Inventory Tasks)
專為大型、有週期性的盤點專案所設計的管理模組。
- **任務資訊 (Tab 1)**：建立任務時可設定「任務名稱」、「起訖日期」與「目標盤點單總數」。
  - *範例：建立「年度資產清查」，設定日期 8/1 - 8/31，目標單數 500 張。系統會產生一個具有手繪進度條的任務卡片。*
- **完成狀態 (Tab 2)**：顯示所有關聯至此任務的盤點單，並帶有分頁與篩選功能（全部 / 進行中 / 已完成）。
  - 此頁籤會列出單號、負責人、派送日、完成日，並自動扣除假日計算出精確的「花費工作天數」。
- **任務報告 (Tab 3)**：提供詳盡的數據與績效圖表。
  - **數據報告**：總結該任務的總花費天數，並頒發 🥇金牌、🥈銀牌、🥉銅牌給完成項目最多的前三名人員。
  - **績效圖表**：內建長條圖、折線圖、綜合圖與圓餅圖。系統採用「雙 Y 軸」設計，完美同時呈現「完成項目數」(數百件) 與「完成比率」(百分比 0-100%)。
  - *範例：切換至「綜合圖」時，左側 Y 軸顯示「盤點單數」的長條柱，右側 Y 軸顯示「完成比率」的折線，資料一目了然。且點擊圓餅圖時，還可以自由切換要顯示項目數還是比率的圓餅分佈。*
  - **在行事曆中查看**：點擊此按鈕，系統會自動跳轉至「行事曆管理」並定位到該任務的起始月份。

### 4. 🎫 盤點單管理 (Inventory Tickets)
負責追蹤每一張盤點單的流向與進度。
- **單筆 / 批次派送**：
  - *範例：使用批次派送輸入「260801」到「260810」，系統一次產生 10 張盤點單。*
- **智慧關聯與防呆機制**：
  - 派送時若選擇了「盤點任務」，系統會嚴格檢查數量。若輸入的單數超過了該任務剩餘可指派的數量，系統會彈出警告阻擋。
  - 若輸入的單號在系統中已經存在，也會被攔截，並用警示顏色標明「單號已被指派」。
- **看板與列表模式切換**：提供直覺的 Kanban 看板拖曳模式，或是緊湊的表格清單模式。
- **進度自動計時**：當盤點單從「盤點中」推進到最後一個「完成」階段時，系統會記錄當下時間，並計算精確的工作天數。若當天派送當天完成，耗費天數會顯示為 0 天。

### 5. 🔍 盤點明細 (Item Details)
針對單張盤點單進行細部物料追蹤。
- **明細資料建檔**：可記錄料號、儲位、數量、單位、淨重等詳細數值。
- **Excel 批次匯入**：支援 `.xlsx` 檔案匯入，系統會自動解析並帶入欄位。
- **視覺化摘要**：明細表上方提供塗鴉風格的統計方塊，清楚展示該單號的項目總數與盤點進度（例如：完成 15/20 項）。

### 6. ⚙️ 盤點流程設定 (Workflows)
高度彈性的 SOP 流程中心。
- 支援自由新增、編輯、刪除盤點階段，並透過上下箭頭調整流程順序。
- *範例：可以將預設流程修改為「待處理 -> 現場初盤 -> 主管複盤 -> 財務過帳 -> 完成」。系統會自動保護第一個（起始）與最後一個（完成）階段不被隨意刪除，確保業務邏輯完整。*

### 7. 📈 統計作業 (Statistics)
幫助管理層進行績效考核與找出流程瓶頸。
- **多維度績效報表**：支援依「人員」、「單號」、「日期」與「任務」來產生直條圖與圓餅圖。
- *範例：選擇「依人員」產生圖表，可以一眼看出哪位員工在這個月處理了最多件數，或是平均花費天數最少。*
- **流程瓶頸分析**：系統會統計每個盤點階段的平均停留天數，若發現「主管複盤」階段停留特別久，主管便能及早介入。

### 8. 🧑‍🤝‍🧑 人員管理 (Personnel)
維護系統的操作人員名單。
- 可設定人員姓名、性別、職稱與工作職責（「盤點」或「主管」）。
- 以大型 SVG 圖示別標示男女，帶有塗鴉風格，具備高視覺辨識度。
- *範例：只有被賦予「盤點」職責的人員，才會出現在派送單號的負責人下拉選單中，也才會顯示在儀表板的績效追蹤區域。*

## 🎨 設計理念 (Design Philosophy)

本系統最大特色在於其 **跳脫傳統的視覺體驗**。工業與倉儲系統經常充滿生硬的直線與密集的表格，容易讓人感到疲乏。本系統大量採用了：
- **不規則手繪框 (`doodle-border`)**：模擬奇異筆的手繪黑框，帶有隨機的粗細與邊角。
- **手寫字體 (Caveat)**：在標題、圖表座標軸與重點數字上套用。
- **微傾斜 (Rotate)**：讓資料區塊、標籤、便利貼帶有 1~5 度的隨機傾斜，打破死板的網格感。
- **馬卡龍色彩**：搭配淡黃、粉紅、淡紫與明亮的綠色與橘色，打造出如兒童繪本般的視覺饗宴，讓使用者在操作繁瑣的盤點作業時，也能保持輕鬆愉悅的心情。
