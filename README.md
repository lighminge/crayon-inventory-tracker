# 🖍️ Crayon Inventory Tracker (塗鴉風盤點管理系統)

這是一個具有高度互動性、使用手繪塗鴉風格 (Doodle Style) 設計的現代化盤點追蹤與管理系統。本系統採用 React + TypeScript 開發，搭配 Firebase 進行資料儲存，並導入完整的角色權限存取控制 (RBAC) 機制，確保各功能模組的安全性與專業度，同時保有活潑的操作體驗。

---

## 🌟 核心特色與設計理念 (Design Philosophy)

本系統打破傳統進銷存系統死板的設計，大膽採用特殊塗鴉風格，旨在讓繁雜枯燥的盤點作業變得生動有趣：
- **手繪框線 (`doodle-border`)**：所有卡片、表格、輸入框與彈出視窗，皆使用不規則的手繪邊框，並伴隨輕微的傾斜角度，充滿活力。
- **高對比色彩**：使用飽和度高的專屬色彩（如塗鴉紫、塗鴉綠、塗鴉紅），來區分不同狀態與功能，直觀且便於識別。
- **一致的自訂提示**：系統全面棄用瀏覽器原生的警告視窗 (Alert/Confirm)，全部改為符合塗鴉風格的彈出對話框，確保視覺體驗的一致性。
- **完整權限管控 (RBAC)**：支援不同層級使用者的功能權限設定，從「無權限」、「僅檢視」到「可編輯」，層層把關。

---

## 🚀 詳細功能說明與使用步驟

### 1. ⚙️ 系統管理與登入機制 (System Management & Auth)
負責管理系統帳號與各模組的權限控制。

- **預設管理員與登入**：
  - 系統內建一組超級管理員帳號密碼：`admin` / `admin`。
  - 使用者必須登入才能進入系統，若未登入將被自動導向登入頁面。
- **帳號與權限設定**：
  - 管理員可於「系統管理」中新增其他帳號，並針對所有 9 大功能模組（儀表板、盤點單派送、盤點單管理、盤點單流程、盤點任務、流程管理、盤點項目明細、人員管理、統計作業）獨立設定權限。
  - **權限等級**：
    - `無權限 (None)`：左側選單將隱藏該功能，無法進入。
    - `僅檢視 (View)`：可進入畫面查看資料，但所有「新增」、「修改」、「刪除」、「推進」等按鈕將自動隱藏或停用。
    - `可編輯 (Edit)`：擁有該模組的完整操作權限。
- **使用步驟**：
  1. 使用 `admin` 登入系統。
  2. 點擊左側「⚙️ 系統管理」。
  3. 點擊「＋ 新增使用者」，輸入帳號、密碼、名稱，並勾選各模組的權限。
  4. 儲存後，該帳號即可使用專屬權限登入。

---

### 2. 📊 儀表板 (Dashboard)
提供全局的營運指標監控。

- **核心指標統計**：
  - 在最上方顯示「總開立單據數」與「總開立項目數」，讓管理者一眼掌握系統總工作量。
  - 同時顯示「未結案單據」與「未結案項目數」。
- **人員績效排行榜**：
  - 以長條圖 (Bar Chart) 列出每位盤點人員的「未結案單據」與「已結案單據」數量對比，快速評估人員負荷。
- **急件與稽催警示**：
  - **超過 7 天未結案之項目**：系統會自動抓取卡關過久的盤點單，並高亮顯示，點擊「去處理」可快速跳轉至盤點單管理。

---

### 3. 📅 行事曆管理 (Calendar Management)
結合台灣節慶，幫助管理者精準計算「預計完成日」。

- **工作日與休假設定**：
  - 系統內建台灣節慶 (API/Mock)，並支援點擊日期將其切換為「一般工作日」、「自訂休假」或「補班日」。
  - 這些設定會影響盤點單的「預計完成日」計算（自動跳過休假日）。
- **當月任務統計指標**：
  - 行事曆上方不僅顯示當月工作天數，還會顯示「當月盤點任務總筆數」、「已完成筆數」與「未完成筆數」，且數字加大加粗，視覺鮮明。

---

### 4. 🎯 盤點任務 (Inventory Tasks)
管理大批次的盤點專案。

- **建立任務與日期區間查詢**：
  - 支援設定任務名稱、目標數量、起始日期，以及「預計花費工作日」。
  - 上方提供「建立日期區間」選取器，可快速過濾出特定期間內建立的任務。
- **任務關聯狀態與刪除保護**：
  - 當任務已經關聯到任何「盤點單」時，該任務將**無法被刪除**（刪除按鈕會變灰並提示），防止誤刪造成資料孤兒。

---

### 5. 📤 盤點單派送與📝 管理 (Dispatch & Tickets)
負責發配盤點單與 Kanban 狀態追蹤。

- **快速派送**：
  - 於「盤點單派送」選擇人員後，填寫單號（如：`260801`）、選擇所屬任務，即可產生盤點單。
- **看板模式 (Kanban)**：
  - 在「盤點單管理」中，盤點單會根據「流程站點」（如：備料中 -> 盤點中）以 Trello 拖曳風格的看板顯示。
- **主管核准與結案機制**：
  - 若流程推進到最後一關，會觸發「主管核准結案」按鈕。
  - 點擊後跳出結案表單，經確認後，系統會自動押上「結案日期」。已結案的單據將反白並**禁止刪除**。

---

### 6. 🔄 盤點單流程 (Workflow Tickets)
專為「大量推進」與「快速流轉」設計的操作中心。

- **批次推進下一關**：
  - 可在表格中勾選多筆盤點單，選擇「統一設定日期」，然後點擊「批次推進至下一關」，系統會一次更新所有勾選單據的狀態。
- **單號快速查詢與處理**：
  - 上方設有「🚀 快速處理」輸入框。
  - **使用步驟**：直接用條碼槍刷入單號，或手動輸入（例如 `260737`），按下「快查推進」，系統會自動彈出該單據的進度推進視窗，極大化作業效率！
- **退回上一關**：
  - 若發現推進錯誤，提供「退回上一關」功能（紅色按鈕），並清除目前站點的完成時間。

---

### 7. ⚙️ 流程管理 (Workflows)
高彈性的 SOP 站點編輯器。

- **自訂站點名稱與負責人**：
  - 管理者可自訂如「備料」、「盤點」、「收料」等流程。
  - 支援上下移動改變順序。
  - 每個站點可綁定「預設負責人」，派送單據時若無指定，則會繼承此負責人。

---

### 8. 📑 盤點項目明細 (Item Details)
針對單張盤點單底下的「每一筆物料」進行精細紀錄。

- **手動新增明細與智能防呆**：
  - 點擊「＋ 手動新增明細」後，可在表格內直接新增一行。
  - 必填欄位為「物料總數」。
  - **智能序號下拉**：系統會判斷該盤點單有幾個項目，自動生成對應數量的序號選單。
  - **子項自動遞增**：選擇序號後，系統會偵測該序號是否已有資料，若有，則子項會自動帶入 `最後子項號碼 + 1` (例如已有 001-1, 001-2，下次選 001 會自動帶入子項 3)。
  - **重複警示**：儲存時若序號與子項與現有資料重複，系統會跳出塗鴉風格的警示視窗確認是否覆蓋。
- **浮動計算機 (`無條件捨去`)**：
  - 點擊畫面左側的「紫色計算機圖示」展開。
  - 輸入「總重量」、「容器數量」、「容器單位」及「物料單位重量」，系統會使用 **無條件捨去** (`Math.floor`) 自動計算出精準的「物料總數(PCS)」。
  - 計算完成後可點擊「套用至目前項目」直接將數值寫入表格。
- **使用步驟**：
  1. 在列表找到欲建檔的盤點單，點擊「項目明細」。
  2. 點擊「＋ 手動新增明細」。
  3. 打開左側計算機，輸入重量資訊得出物料總數，點擊套用。
  4. 選擇序號，檢查子項號碼。
  5. 點擊「儲存」按鈕（綠色），若重複會跳出警示，確認後完成建檔。

---

### 9. 📈 統計作業 (Statistics)
將系統所有資料進行彙整與圖表化分析。

- **多條件過濾器**：
  - 支援「西元年度」選取（同儀表板功能，按年度區分資料）。
  - **依盤點任務**：加入「全選 / 全取消」功能，並會在選項旁顯示「已選取的任務數量統計」。
  - **依盤點單完成日數**：新增下拉選單，可篩選花費 `0天`、`1天` ... `7天以上` 結案的盤點單，精準找出效率瓶頸。
- **多維度圖表分析**：
  - 可切換查看「人員績效」、「平均結案天數」等指標。
  - 支援長條圖 (Bar)、圓餅圖 (Pie)、折線圖 (Line) 切換。

---

### 10. 👥 人員管理 (Personnel)
建立系統的員工與角色配置。

- 支援建立人員名稱、角色（如：備料、行政、主管），並可標記是否為「盤點人員」。
- 若勾選「盤點人員」，該員才會出現在儀表板的績效統計，並能在派送單據時被選為負責人。
