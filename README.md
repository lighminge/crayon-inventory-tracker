# 🖍️ Crayon Inventory Tracker (塗鴉風盤點管理系統)

這是一個具有高度互動性、使用手繪塗鴉風格 (Doodle Style) 設計的現代化盤點追蹤與管理系統。本系統採用 React + TypeScript 開發，搭配 Firebase 進行資料儲存，並導入完整的角色權限存取控制 (RBAC) 機制，確保各功能模組的安全性與專業度，同時保有極致活潑的操作體驗。

---

## 🌟 核心特色與設計理念 (Design Philosophy)

本系統打破傳統進銷存系統死板的設計，大膽採用特殊塗鴉風格，旨在讓繁雜枯燥的盤點作業變得生動有趣：
- **手繪框線 (`doodle-border`)**：所有卡片、表格、輸入框與彈出視窗，皆使用不規則的手繪邊框，並伴隨輕微的傾斜角度，充滿活力。
- **高對比色彩**：使用飽和度高的專屬色彩（如塗鴉紫、塗鴉綠、塗鴉紅），來區分不同狀態與功能，直觀且便於識別。
- **一致的自訂提示**：系統全面棄用瀏覽器原生的警告視窗 (Alert/Confirm)，全部改為符合塗鴉風格的彈出對話框，確保視覺體驗的一致性。
- **完整權限管控 (RBAC)**：支援不同層級使用者的功能權限設定，從「無權限」、「僅檢視」到「可編輯」，層層把關。

---

## 🚀 詳細功能說明與使用範例

本系統包含 10 大核心功能模組，以下詳細說明各模組的功能及實際應用範例：

### 1. ⚙️ 系統管理與安全監控 (System Management & Login Records)
負責管理系統帳號、權限控制，以及詳實記錄系統的登入歷史。

- **預設管理員與登入限制**：
  - 系統內建一組超級管理員帳號：`admin`，該帳號被鎖定保護，無法被刪除，避免誤刪導致系統無法登入。
  - 使用者必須登入才能進入系統，未登入將被自動導向登入頁面。
- **帳號與權限設定 (RBAC)**：
  - 支援建立無限組帳號，並可將帳號綁定（對應）至「人員管理」中的特定人員。
  - 針對 9 大功能模組皆可獨立設定權限：
    - `無權限`：該功能會從左側導覽列徹底隱藏。
    - `僅檢視 (唯讀)`：可進入畫面查看資料，但無法進行新增、修改、刪除。例如在「盤點項目明細」若只有唯讀權限，左側計算機的「匯入至此明細」按鈕將會鎖定變灰，無法寫入。
    - `可編輯 (完整)`：擁有該模組的所有操作權限。
- **系統登入記錄 (全新擴充功能)**：
  - 詳細記錄每位使用者的登入與登出時間（精確至秒），並自動抓取來源 IP（透過 ipify）。
  - **圖表分析與匯出**：提供視覺化的長條圖與折線圖，統計每日登入次數（資料點上方會直接顯示數值），並支援將圖表匯出為 PNG 圖檔。
  - **條件篩選與報表匯出**：支援依「年/月/日」分開選取，或透過下拉選單指定人員進行查詢。查詢結果除了可依照時間排序外，更可一鍵匯出為 Excel 報表。
- **👉 使用範例**：
  - *情境*：廠長希望了解這個月有哪些人登入過系統。
  - *操作*：廠長進入「系統管理」>「系統登入記錄」，將日期選單設定為該月，系統即會列出該月所有登入紀錄、IP 位置，並可點擊「匯出 Excel」將資料交給稽核部門。

### 2. 📊 儀表板 (Dashboard)
提供全局的營運指標監控，將最重要的盤點資訊濃縮於首頁。

- **四大核心指標排版**：
  - 畫面最上方將「處理中單據 (含總數對比)」、「處理中項目數 (含總數對比)」、「整體完成率」與「平均處理天數」並列於同一行，視覺美觀且易於閱讀。
- **任務狀態快速切換**：
  - 內建「切換盤點任務」功能，並提供「全部」、「已過期」、「未過期」的勾選過濾器，讓管理者能迅速聚焦於急迫的任務。
- **人員績效排行榜**：
  - 以長條圖列出每位盤點人員的「未結案單據」與「已結案單據」數量對比，快速評估各人員的負荷量。
- **急件與稽催警示**：
  - 系統會自動抓取卡關過久（超過 7 天未結案）的盤點單並高亮顯示。
- **👉 使用範例**：
  - *情境*：主管每天早上登入系統。
  - *操作*：首頁直接顯示目前處理中的單據為 `19 / 總開立 88`。主管發現下方有 3 筆紅色高亮的急件，點擊「去處理」便能直接跳轉至該單據進行稽催。

### 3. 📅 行事曆管理 (Calendar Management)
結合台灣節慶，幫助管理者精準計算盤點單的「預計完成工作日」。

- **工作日與休假設定**：
  - 內建台灣節慶 (API/Mock)，點擊日期即可切換為「一般工作日」、「自訂休假」或「補班日」。
  - **權限防呆**：當使用者權限為「唯讀」時，點擊日期將不會有任何反應，無法新增或修改休假。
- **任務與工時計算**：
  - 這些休假設定會直接影響盤點單的「預計完成日」計算（系統會自動跳過休假日，只算工作日）。
  - 行事曆上方不僅顯示當月工作天數，還會醒目顯示「當月任務總筆數」、「已完成」與「未完成」數量。
- **👉 使用範例**：
  - *情境*：遇到突發的颱風假。
  - *操作*：擁有編輯權限的管理者進入行事曆，點擊明天的日期設為「自訂休假」。系統後續在計算所有盤點單的到期日時，會自動將期限順延一天。

### 4. 🎯 盤點任務 (Inventory Tasks)
管理大批次的盤點專案，作為單據的上層容器。

- **建立任務與日期區間查詢**：
  - 支援設定任務名稱、目標數量、起始日期，以及「預計花費工作日」。
  - 提供建立日期的區間選取器，可快速過濾出特定期間內的任務。
- **任務關聯狀態與刪除保護**：
  - 當任務底下已經開立了「盤點單」時，該任務將**受到保護無法被刪除**（按鈕會變灰並提示），防止誤刪造成資料孤立。
- **👉 使用範例**：
  - *情境*：年底準備進行年度大盤點。
  - *操作*：建立一個「2026年終大盤點」任務，目標數量 5000 筆，預計花費 10 個工作日。後續派發單據時，將所有單據歸屬到此任務下以便追蹤。

### 5. 📤 盤點單派送與📝 管理 (Dispatch & Tickets)
負責發配盤點單，並透過 Kanban 看板直觀追蹤各單據狀態。

- **快速派送**：
  - 於「盤點單派送」選擇人員、填寫單號（例如：`260801`）、選擇所屬任務，即可完成單據派發。
- **看板模式 (Kanban)**：
  - 在「盤點單管理」中，盤點單會根據「流程站點」（如：備料中 -> 盤點中）以 Trello 拖曳風格的看板分類顯示。
- **主管核准與結案機制**：
  - 流程推進到最後一關時，會觸發「主管核准結案」按鈕。點擊後跳出結案表單，經確認後，系統會自動押上「結案日期」。已結案的單據將反白並**禁止刪除**。
- **👉 使用範例**：
  - *情境*：倉庫人員完成了一批物料的清點。
  - *操作*：在「盤點單管理」看板中，將該單據從「盤點中」拖曳到「主管覆核」。主管登入後，點擊該單據的「核准結案」，單據正式歸檔，且從此無法再被誤刪。

### 6. 🔄 盤點單流程 (Workflow Tickets)
專為第一線人員設計，主打「大量推進」與「快速流轉」的作業中心。

- **批次推進下一關**：
  - 在表格中勾選多筆盤點單，設定好日期後，點擊「批次推進至下一關」，系統會一次將所有單據移動至下一個流程站點。
- **單號快查與條碼槍支援**：
  - 上方設有「🚀 快速處理」輸入框。可直接用條碼槍刷入單號，系統會自動彈出該單據的進度推進視窗，極大化作業效率！
- **退回上一關**：
  - 若發現推進錯誤，提供紅色的「退回上一關」功能，並自動清除該站點的完成時間。
- **👉 使用範例**：
  - *情境*：現場人員手上有 10 張實體盤點單已經清點完畢。
  - *操作*：人員不需用滑鼠慢慢找，直接游標點擊「快速處理」框，用條碼槍連嗶 10 張單據，嗶一張就按一次確認推進，5 秒內即可完成 10 張單據的系統更新。

### 7. 🔀 流程管理 (Workflows)
高彈性的 SOP 站點編輯器，讓企業自訂專屬的盤點流程。

- **自訂站點名稱與負責人**：
  - 管理者可自由新增、修改如「備料」、「盤點」、「收料」、「會計覆核」等流程站點。
  - 支援上下拖曳移動來改變站點順序。
  - **預設負責人繼承**：每個站點可綁定「預設負責人」，派送單據時若未特別指定，就會自動交由該預設負責人處理。
- **👉 使用範例**：
  - *情境*：公司導入新規定，盤點完必須經過「稽核部」確認。
  - *操作*：進入「流程管理」，在「主管覆核」之後新增一個站點叫做「稽核確認」，並將負責人預設綁定為稽核員小明。以後所有的盤點單跑到最後都會自動指派給小明。

### 8. 📑 盤點項目明細 (Item Details)
針對單張盤點單底下的「每一筆物料」進行最精細的紀錄與防呆。

- **手動新增明細與智能序號下帶**：
  - 點擊「＋ 手動新增明細」即可在表格內新增一行。
  - **智能序號與子項**：系統會自動根據該單據現有項目生成序號。若選擇既有序號，系統會偵測並自動帶入 `最後子項號碼 + 1` (例如已有 001-1, 001-2，下次選 001 會自動變 001-3)。
  - **重複警示**：若序號與子項在存檔時發現重複，系統會跳出塗鴉風格警示，確認是否真的要覆蓋。
- **浮動計算機 (無條件捨去機制)**：
  - 點擊畫面左側的紫色計算機圖示即可展開。
  - 輸入「總重量」、「容器數量」、「容器單位重」及「物料單位重」，系統會使用 **無條件捨去** (`Math.floor`) 精準計算出「物料總數(PCS)」。
  - 計算完成後可點擊「📥 匯入至此明細」直接將數值寫入表格。（若權限為唯讀則無法匯入）。
- **👉 使用範例**：
  - *情境*：盤點一批螺絲，總重 10.5 kg，裝在 2 個 0.5 kg 的籃子裡，單顆螺絲重 10 g。
  - *操作*：在計算機輸入 10.5 (總重)、2 (容器數)、0.5 (容器重)、10 (單重)。系統自動扣除籃子重量後，計算出 950 顆。點擊匯入，950 直接填入表格，避免人工算錯。

### 9. 📈 統計作業 (Statistics)
將系統所有資料進行多維度的彙整與圖表化分析。

- **多條件精準過濾器**：
  - 支援「西元年度」選取，並可依「盤點任務」進行過濾（內建全選/全取消按鈕與數量統計）。
  - **依盤點單完成日數**：新增了下拉選單，可篩選出花費 `0天`、`1天` ... `7天以上` 結案的盤點單，精準找出效率極端值。
- **多維度圖表切換**：
  - 提供「人員績效」、「平均結案天數」等統計維度。
  - 支援一鍵切換 長條圖 (Bar)、圓餅圖 (Pie) 與折線圖 (Line) 呈現。
- **👉 使用範例**：
  - *情境*：總經理要求提出上個月的處理效率報告。
  - *操作*：進入「統計作業」，篩選條件設定為該月份的任務，並查看「完成日數」。發現有 15% 的單據花費了 7 天以上才結案。可直接將該長條圖截圖或匯出，作為月會檢討素材。

### 10. 👥 人員管理 (Personnel)
建立系統的員工與角色配置名單。

- **人員與盤點屬性設定**：
  - 支援建立人員名稱、職稱（如：備料員、倉管主管）。
  - 可特別標記是否為「盤點人員」。若勾選，該人員才會出現在「儀表板」的績效統計榜單中，並能在派送單據時被選取為負責對象。
- **結合帳號對應**：
  - 這裡建立的人員，可以在「系統管理」中與「登入帳號」綁定，讓系統明確知道哪個帳號是屬於哪位真實員工。
- **👉 使用範例**：
  - *情境*：新人小華報到，負責現場盤點。
  - *操作*：先在「人員管理」新增小華，勾選為「盤點人員」。接著到「系統管理」建立帳號 `hua`，並在「對應人員連結」下拉選單中選擇小華。從此小華登入系統作業，所有操作紀錄皆有跡可循。
