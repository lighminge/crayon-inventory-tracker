# Crayon Inventory Tracker (蠟筆盤點系統)

這是一個以現代網頁技術建構、專為製造與倉儲量身打造的**盤點追蹤管理系統**。系統以活潑的「手繪塗鴉風格」 (Crayon/Doodle UI) 為視覺主軸，打破傳統系統的冰冷與生硬，旨在降低使用者的操作疲勞、提升視覺豐富度與使用體驗。

經過多次版本迭代，系統已具備強大、彈性的盤點管理與追蹤數據能力。

---

## 🛠 核心技術架構
- **前端框架**：React + TypeScript + Vite
- **UI 風格**：純手寫 Vanilla CSS 塗鴉風格 (包含 Caveat 字體、手繪邊框設計、高對比柔和色彩、傾斜排版)
- **圖表呈現**：Recharts
- **後端與資料庫**：Firebase (Firestore) 雲端資料庫

## 📖 詳細功能說明與操作手冊

### 1. 📊 儀表板 (Dashboard)
儀表板是系統的首頁，能讓管理者以最快速度掌握盤點任務進度與人員績效。
- **年度過濾與任務篩選**：
  - 系統右上角提供「西元年度」與「盤點任務」的下拉選單。
  - **範例**：當選擇「2026 年」時，儀表板所有的數據卡片、圖表與未結案清單，都會自動過濾出 2026 年派送的資料。若進一步選擇特定的「盤點任務」，則只會顯示該任務的相關數據。
- **專屬人員績效卡片**：
  - 列出所有具備「盤點人員」權限的使用者，並為每個人計算專屬數據。
  - 卡片內含三個頁籤：
    - **統計(預設)**：顯示該人員「本月派送件數」、「本月完成件數」、「完成率進度條」與「平均完成天數」。
    - **未完成**：以列表列出該人員目前負責但尚未結案的盤點單，並附有分頁功能（每 5 筆一頁）。
    - **盤點中**：特別標示正處於「盤點中」階段的急件清單。
- **整體數據圖表**：
  - 支援「長條圖 (Bar)」、「折線圖 (Line)」與「混合圖 (Composed)」，並可切換查看「盤點單數量」或「盤點項目總數」。
  - **範例**：管理者可點擊切換為「折線圖」，觀看各個人員在「盤點單數量」的表現走勢。
- **全域未結案清單與圓餅圖**：
  - 統整目前全系統尚未結案的盤點單，並依照「目前卡在哪個流程節點（等候誰處理）」進行分組。
  - 提供清單列表與圓餅圖兩種檢視模式，可快速揪出流程瓶頸。

### 2. 📅 行事曆管理 (Calendar Management)
結合日曆介面，幫助管理者輕鬆掌控每日的派送任務與盤點單。
- **當月數據總覽**：
  - 在日曆上方，以醒目的視覺列出「當月盤點任務總數」、「當月已完成盤點任務總數」與「當月未完成盤點任務總數」。
  - 數字採用放大與強烈色彩設計，完全符合塗鴉風格。
- **任務與盤點單顯示**：
  - 行事曆每天的格子中會顯示該日派送的「盤點任務」與「盤點單」。
  - 盤點單若已完成（有結案日期），會在單號前方標記 `(完)`。
  - **範例操作**：在日曆上點擊特定盤點單（如 `260801`），系統會彈出詳細資訊視窗，顯示該單的負責人、目前進度、以及各階段完成日期。
- **工作日與假日排除設定**：
  - 系統內建假日設定功能，可以手動將特定日期標記為「假日」或「工作日」。
  - 計算「平均完成日數」時，系統會自動扣除被標記為假日的天數，讓績效計算更精準。

### 3. 📋 盤點任務管理 (Inventory Tasks)
用來建立與管理大批次盤點作業，可視為盤點單的「群組」或「批次專案」。
- **任務列表與查詢**：
  - 列表上方可依據「日期區間」過濾任務。
  - **範例**：設定起始日期為 2026/08/01，結束日期為 2026/08/31，即可查出 8 月份建立的所有盤點任務。
- **新增/編輯任務**：
  - 建立時可填寫「任務名稱」、「起始日期」、「預計結束日期」、「目標總筆數」以及「盤點類型（夾鉗 或 TKW）」。
  - **範例**：點擊「＋ 新增盤點任務」，輸入名稱「2026 Q3 夾鉗盤點」，選擇盤點類型為「夾鉗」，設定目標筆數為 500。
- **自動進度計算**：
  - 任務會自動關聯底下的盤點單，並計算「目前已建檔筆數」以及「達成率（%）」。

### 4. 📝 盤點單管理 (Inventory Tickets)
負責追蹤每一張盤點單的流向、負責人與處理進度。
- **建立與指派盤點單**：
  - 支援快速新增，填入盤點單號（如 `260737`）、關聯盤點任務，並指定負責的盤點人員與項目總數。
  - **動態指派機制**：流程若設定為「指派盤點人員」，系統會自動帶入該單的負責人，無須寫死固定人員。
- **看板模式與列表模式切換**：
  - 支援 Trello 風格的「看板模式 (Kanban)」，可將盤點單依照流程階段分欄顯示。
  - **範例**：管理者在看板模式中，可以清楚看到「等候盤點」欄位有 3 張單，「盤點中」欄位有 2 張單，一目瞭然。
- **更新進度階段**：
  - 點擊盤點單的「✏️」按鈕，可進入編輯視窗，展開下方的「更新進度」區塊。
  - 點擊「前往下一階段」按鈕，系統會自動記錄當下時間，並將盤點單推至下一個 SOP 流程。若抵達最終階段，則系統會自動押上「結案日期」。

### 5. 🔍 盤點項目明細 (Item Details)
盤點單底下的細部物料紀錄，提供強大的手動輸入與匯入機制。
- **查詢與過濾功能區**：
  - 支援多維度篩選：啟用日期區間、單號篩選、盤點類型（夾鉗/TKW）、盤點單狀態（已結案/未結案）。
  - 單號過濾採用精確的清單篩選，可以快速定位所需的明細資料。
- **🧮 浮動計算機工具**：
  - 畫面左側固定有一顆紫色的「🧮 計算機」按鈕，點擊後會展開塗鴉風格的計算機面板。
  - **無條件捨去計算**：輸入「總重量」、「容器數量」、「容器單重」後，系統會自動扣除容器重量得出「淨重」。再輸入「物料單重（公克）」，系統會採用**無條件捨去**公式（`Math.floor`）自動算出「物料總數（PCS）」。
  - **容器類型英文代碼**：容器類型下拉支援 鐵桶 (T)、塑膠箱 (P)、紙箱 (B)、摺疊籠 (L)、鐵架 (J)，匯入時會自動使用對應的英文代碼。
  - **一鍵匯入防呆**：計算完畢後，點擊「📥 匯入至此明細」，系統會檢查「盤點單號」與「項目序號-子項」是否已存在。若重複會跳出警告視窗詢問是否覆蓋。
- **手動新增功能**：
  - 點擊「＋ 手動新增明細」按鈕，列表最上方會出現編輯列。
  - **智能序號下拉選單**：系統會根據該盤點單的「項目總數」自動產生下拉選單（例如：總數為 5，則產生 001~005 的選項）。
  - **子項自動遞增**：當您選擇了序號（如 001），系統會自動偵測該序號是否已有資料，並將子項自動帶入最後一筆 `+1` 的數字（如 001 已有 2 筆，則自動帶入 3）。
  - 必填欄位僅有「序號」與「物料總數」，並具備重複資料的自訂視窗警告與取消防呆機制。

### 6. ⚙️ 工作站流程設定 (Workflows)
高彈性的 SOP 流程自訂功能。
- **自訂階段名稱與順序**：
  - 管理者可以新增、刪除或拖曳排序工作站流程。
  - **範例**：可建立「等候派送」->「盤點中」->「等候初核」->「等候複核」的流程。系統將依照此順序來推進盤點單。
- **指派特定負責人**：
  - 每個流程階段都可以指派特定的「主管/人員」來負責。或者選擇「(指派盤點人員)」，讓系統根據盤點單動態決定。

### 7. 📈 統計作業 (Statistics)
將系統所有資料進行彙整、分析並提供決策報表。
- **西元年度全域過濾**：
  - 標題右側設有「西元年度」選單，切換後下方的圖表與稽催報表都會即時聯動，只顯示該年度的資料。
- **多條件組合篩選**：
  - 提供強大的「設定統計條件」面板。可以勾選啟用：日期區間、單號起迄區間。
  - **依盤點任務**：可選擇特定任務（支援「全選」、「全取消」，並依據盤點類型連動過濾）。
  - **依盤點單完成日數**：可過濾出完成天數為 0天、1天... 甚至 7天以上的單子。
- **統計圖表**：
  - 提供三種分析維度：人員表現（總數量、完成率、平均天數）以及階段耗時分析。
  - 可動態切換圖表呈現方式（長條圖、圓餅圖、折線圖）。
- **稽催報表 (Expediting Report)**：
  - 專門用來追蹤「卡關」的盤點單。
  - 列出各階段目前積壓的單量與負責人，並標示出停滯最久的盤點單（包含停滯天數），幫助管理者及時介入稽催。

### 8. 👥 人員管理 (Personnel)
建立系統的帳號與角色配置。
- 支援建立人員並指定其職稱。
- 可勾選人員是否具備「盤點人員」角色。只有被勾選為盤點人員的帳號，才會出現在儀表板的績效卡片中，並可被指派負責盤點單。

## 🎨 塗鴉風格設計理念 (Design Philosophy)

系統大量採用了特殊的塗鴉風格，旨在讓枯燥的盤點作業變得生動有趣：
- **手繪邊框 (`doodle-border`)**：所有的卡片、按鈕與彈出視窗，都擁有不規則的手繪邊框，並伴隨輕微的傾斜角度（Rotate）。
- **手寫字體 (Caveat)**：在標題、圖表與重點數據上，使用了手寫字體來增加人情味。
- **高對比色彩**：使用飽和度高的蠟筆色彩（如紫色、藍色、紅色、橘色）來區分不同的狀態與按鈕功能，直觀且便於識別。
- **系統化自訂視窗**：拋棄了瀏覽器原生的警告視窗 (Alert/Confirm)，全面改用符合系統塗鴉風格的彈出對話框，確保視覺體驗的一致性。
