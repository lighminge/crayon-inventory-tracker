# Crayon Inventory Tracker (塗鴉風盤點追蹤系統)

這是一個以現代網頁技術構建、專為製造與倉儲現場設計的**盤點追蹤管理系統**。系統以活潑生動的「手繪塗鴉風格」 (Crayon/Doodle UI) 作為視覺核心，將枯燥的盤點與績效管理轉化為清晰、直覺且充滿互動感的使用體驗。

---

## 🛠️ 技術架構
- **前端框架**：React + TypeScript + Vite
- **UI 呈現**：客製化 Vanilla CSS 手繪塗鴉風格 (包含 Caveat 手寫字體、手繪不規則外框)
- **圖表套件**：Recharts
- **後端與資料庫**：Firebase (Firestore) 實時資料庫

---

## 🌟 核心功能詳細說明

### 1. 📊 儀表板 (Dashboard)
儀表板是系統的核心指揮中心，讓管理者能以最快的速度掌握目前所有盤點任務的進度。
- **西元年度全域過濾**：系統支援以「西元年度」為單位的全域資料切換（預設為全部年度）。每個年度的盤點資料皆為獨立計算，切換後，下方的圖表與人員績效卡片會自動更新為該年度的資料。
- **盤點任務聯動篩選**：可透過下拉選單選擇指定的「盤點任務」，系統將立刻鎖定該任務，並顯示專屬的任務進度摘要區塊（包含：已開立品項數、剩餘數量及總達成率）。
- **視覺化統計圖表**：提供長條圖、折線圖及複合圖，支援檢視「盤點單數量」與「盤點項目總數」的近半年趨勢。
- **備料員盤點情況卡片**：
  - 獨立列出每位具備「盤點」職責的人員卡片。
  - **統計數據分頁**：顯示該人員目前的「總未完成」、「已完成總項目數」、「本月總派送」及「本月總完成」。
  - **清單分頁**：分為「未完成」及「盤點中」清單。支援分頁功能（每頁 5 筆），清單內會明確標示出對應的「盤點任務」標籤。人員卡片右上角配有手繪風的傾斜紅色徽章，強烈提示待辦數量。

### 2. 📋 盤點任務管理 (Inventory Tasks)
專為大型或週期性盤點專案（例如：「2026 年度大盤點」或「Q3 夾鉗清查」）設計的管理功能。
- **任務建立與設定**：管理者可建立盤點任務，並設定「有效起訖日期」、「預期總品項數量」以及「盤點類型（夾鉗 / TKW）」。
- **進度與狀態追蹤**：
  - **進度條顯示**：在任務資訊卡中，系統會自動加總所有已關聯至該任務的盤點項目總數，並以長條進度圖呈現開立比例。
  - **完成狀態檢視**：獨立的完成狀態分頁，將所有綁定該任務的盤點單條列顯示。支援狀態篩選（全部、未完成、已完成），並附帶醒目的序號與人員總計，讓管理者隨時追蹤任務是否如期達標。

### 3. 📤 盤點單派送 (Dispatch Tickets)
將盤點作業高效且精準地指派給指定人員。
- **單筆 / 批次派送**：
  - **單筆派送**：輸入特定的盤點單號與品項數量。
  - **批次派送**：輸入起始單號與結束單號 (例如 `260701` 到 `260705`)，系統便會自動產生連續編號的多筆單據。
- **智慧關聯與防呆機制**：
  - **任務連動**：當在派送時選取了「關聯盤點任務」，系統會**自動對應並切換**為該任務設定的盤點類型。
  - **動態進度提示**：選取任務後，派送彈出視窗內會出現顯眼的「任務進度狀況」方塊，提示目前剩餘的可用項次。
  - **數量警告**：當輸入的盤點項目數量超過該任務「剩餘可開立品項數」時，系統會跳出警告畫面。
  - **重複指派攔截**：若輸入的單號在系統中已經存在，會立即鎖定派送並以警示色彩提示該單號目前「已被分派給某位人員」。

### 4. 🗂️ 盤點單流程與管理 (Workflow Tickets)
負責追蹤每一張盤點單的流向與結案進度。
- **卡片與表格雙模式切換**：提供直覺的 Kanban 看板模式與緊湊的表格清單模式。
- **彈性過濾**：支援根據單號、派送日期、負責人員、年度/月份以及「盤點任務」進行交叉篩選。
- **進度推進與耗時計算**：一鍵點擊即可將單據推進至下一階段。系統會自動記錄時間戳記，並精準計算耗時（扣除週末之工作日）。若派送日期與完成日期為同一天，系統會精確顯示耗時為「0 天」。

### 5. 📑 盤點項目明細 (Item Details)
針對單張盤點單進行細部物料追蹤與資料建檔。
- **明細資料建檔**：可記錄各別項次的「毛重、容器類型、容器數量、單重、淨重」等詳細數值。
- **Excel 批次匯入**：支援 `.xlsx` 格式的檔案匯入，系統會自動解析資料並帶入欄位。
- **視覺化摘要區塊**：在明細表上方提供「盤點單統計摘要」，利用帶有大圓圈序號（如 ①、②）的塗鴉風區塊，清晰展示該單據的項目總數與進度。

### 6. 📈 統計作業 (Statistics)
幫助管理層進行長期績效考核與瓶頸分析。
- **多維度績效報表**：支援依據人員、單號、日期及任務來產生直條圖與圓餅圖，檢視「總開立件數」與「平均處理天數」。
- **流程瓶頸分析**：系統會自動計算各個盤點階段（例如：盤點中 -> 複盤 -> 收單）的平均耗時，若某階段耗時過長，主管便能及早介入。

### 7. ⚙️ 盤點單流程設定 (Workflows)
高度彈性的 SOP 流程自訂中心。
- 支援動態新增、編輯、刪除盤點階段，並透過上/下箭頭自由調整流程的先後順序。
- 系統自動防護第一階段與最後階段，確保業務邏輯完整性不被破壞。

### 8. 👥 人員管理 (Personnel)
維護系統的操作人員名單與職權。
- **詳細資料建檔**：包含姓名、性別、職稱與工作職責（如「盤點」或「主管」）。
- **圖示化性別辨識**：採用大型 SVG 圖別標示（男/女/其他），取代傳統文字，提升視覺辨識度。
- **職責連動**：賦予「盤點」職責的人員，才會出現在派送單據與儀表板的追蹤名單中，便於分層管理。

## 🎨 設計理念 (Design Philosophy)

本系統最大特色在於**無壓力的視覺體驗**。工業或倉儲系統經常充滿生硬的直線與密集的表格資料，而本系統大量採用了：
- **不規則邊框 (`doodle-border`)**：模擬手繪畫筆的黑線外框。
- **手寫字體 (Caveat)**：在標題、圖表座標軸與重點數字上套用。
- **微傾斜 (Rotate)**：讓資訊卡片、標籤、便利貼帶有 1~5 度的隨機傾斜，打破死板的網格感。
- **柔和色彩**：搭配馬卡龍色系（淡黃、淡粉、淡紫）營造出如同繪本般的視覺饗宴。
