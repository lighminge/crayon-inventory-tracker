# 🖍️ Crayon Inventory Tracker (手繪塗鴉風 盤點單管理系統)

這是一個以「手繪塗鴉風格 (Doodle/Crayon Style)」打造的現代化盤點單與任務管理系統。除了擁有活潑、獨特的使用者介面外，底層架構完全採用 React + TypeScript + Firebase，具備完整的權限控管、動態工作流程、即時數據圖表，以及高度彈性的報表匯出功能。

---

## ✨ 核心特色與風格設計

- **手繪童趣介面**：全站採用自訂的手繪風格 CSS (`doodle-border`, `doodle-button`, `doodle-input`)，搭配 `Caveat` 字體，讓枯燥的盤點作業變得活潑有趣。
- **直覺式撕頁日曆**：在儀表板中，日期卡片被設計成實體的「撕頁日曆」樣式（帶有頂部裝飾孔與虛線），極具視覺辨識度。
- **專屬人員識別色**：系統自動為每位盤點人員分配獨立、固定的代表色，無論是在長條圖、圓餅圖還是列表文字中，都能一眼識別對應負責人。

---

## 🚀 詳細功能模組說明

### 1. 📊 儀表板 (Dashboard)
儀表板是系統的核心中樞，提供管理者最即時的宏觀數據與微觀進度。

- **當週盤點單派送狀況 (日曆與圖表視圖)**
  - **撕頁日曆卡片**：以星期一至星期五的週曆形式，呈現當週的派送單量。如果當天有休假，會自動標示紅色休假字樣與說明。
  - **互動式展開**：點擊任一有派單的日期（或當週總計卡片），卡片會自動放大，並展開顯示「當天每位人員各自被派發了幾筆單據」，且文字皆套用人員專屬顏色。
  - **當月圖表檢視**：點擊切換後，系統會直接在原區塊內展開一張直列長條圖，顯示當月各人員的總派送件數。
  - **圖片匯出**：只需點擊右上角「🖼️ 匯出圖檔」，就能將當月圖表連同人員統計圖例，直接下載成 PNG 圖片供報告使用。
  - *(範例：廠長想知道這週的派單狀況，打開儀表板就能看到週三有 15 筆派送，點擊週三卡片，馬上展開得知小明 10 筆、小華 5 筆；點擊「當月圖表檢視」還能匯出整個 8 月的業績長條圖。)*

- **備料員盤點情況 (人員進度追蹤)**
  - 以卡片形式列出所有盤點人員，顯示其個人大頭貼、處理中單據數、已結案單據數與總項目數。
  - **雙進度條顯示**：每張卡片皆包含「單據完成率」與「項目完成率」兩組進度條，並有明確文字標示。
  - *(範例：想知道小華今天的效率，可以在卡片上直接看到他的「單據完成率」為 80% (8/10筆)，且點擊卡片即可展開他目前正在處理中的那 2 筆單據明細。)*

- **整體進度與未結案統計**
  - **整體進度儀表**：提供全公司的單據達成率、項目達成率與平均處理天數。
  - **未結案視覺化**：右方區塊可切換長條圖或圓餅圖，快速找出是哪個負責人卡了最多的「未結案單據」。

### 2. 📝 盤點單管理 (Inventory Tickets)
所有盤點單的資料中心，支援強大的篩選、排序與編輯功能。

- **多維度篩選**：可根據「一般/追加」、「年份」、「所屬任務」、「負責人」、「單據類型 (盤點/複盤)」與「當前關卡狀態」進行組合篩選。
- **批次處理功能**：支援勾選多筆單據，一鍵將它們推進到下一個工作流程關卡，大幅節省操作時間。
- **流程日期與派送日連動**：
  - 點擊編輯單據，可使用日曆選擇器修改單據在各個關卡的「通過日期」。
  - 若清除某關卡的日期，等同於「退回該關卡」。
  - **智慧連動**：當修改第一關（盤點單派送）的日期時，系統會自動在底層同步修改該單據的「派送日」，確保儀表板的日曆統計完全零誤差。
  - *(範例：原本昨日派送的單據，管理員發現日期建錯，進入盤點單管理編輯，將「盤點單派送」日期改為今日，儲存後，儀表板的今日卡片數量會自動 +1。)*

### 3. 📤 盤點派發 (Dispatch Tickets)
專為快速建立大量單據而設計的表單。
- **自動產生單號**：輸入所需的資訊與項目數量，系統自動產生並驗證盤點單號。

### 4. 📈 統計報表 (Statistics)
專業的數據分析與高階匯出中心。
- **平均天數分析**：以折線圖或長條圖顯示每位員工完成盤點所需的平均天數。
- **無縫 ExcelJS 原生匯出**：（已排除傳統 `xlsx` 套件的資安漏洞）
  - **個人統計匯出**：可匯出個別人員的 Excel，內含總計與公式。
  - **圖表嵌入匯出 (Excel)**：點擊「匯出 Excel 檔」時，系統會在背景透過 Canvas 擷取目前網頁上的視覺化圖表，並將圖片直接 **貼入** 下載的 Excel 檔案中。
  - *(範例：月底要向高層匯報，主管進入統計報表點擊「匯出所有人員報表」，下載的 Excel 裡面不僅有各欄位數據，旁邊還直接附上一張精美的長條統計圖，免去手動截圖貼上的麻煩。)*

### 5. ⚙️ 工作流程與系統管理
高度客製化的底層設定，適應不同公司的作業模式。
- **工作流程設定 (Workflow)**：
  - 自由新增、排序、刪除單據的關卡。預設為「盤點單派送 ➔ 盤點單繳回 ➔ 盤點數確認 ➔ 盤點數比對 ➔ 主管核准」。
  - 系統的進度追蹤與結案邏輯皆會跟隨此設定動態變化。
- **任務管理 (Tasks)**：
  - 將多張盤點單歸屬到一個「大型任務」之下（例如：2026年度大盤點），方便追蹤整檔活動的進度。
- **休假行事曆 (Calendar Management)**：
  - 設定公司的國定假日或特休，儀表板會自動將該日期標記為休假，並停止計算該日的「處理天數」。
- **人員管理 (Personnel)**：
  - 建立員工檔案、設定大頭貼，並分配職務權限 (角色)。

## 🛠️ 技術架構與資安特點
- **前端框架**：React 18 + TypeScript + Vite
- **UI 與圖表**：自定義 CSS (Doodle Style) + Recharts 數據視覺化圖表
- **匯出引擎**：`exceljs` (處理 Excel 結構與公式) + `html2canvas` (處理圖表截圖轉換)
- **後端與資料庫**：Firebase Firestore (即時資料庫) + Firebase Authentication (驗證機制)
- **資安防護**：
  - 完全移除存在 Prototype Pollution / ReDoS 弱點的舊版 `xlsx` 套件。
  - 匯出功能全面改寫為現代化且安全的 `exceljs` Blob 處理模式。
  - 結合 Firebase App Check 確保 API 來源合法。
